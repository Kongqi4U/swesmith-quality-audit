## 5. loss-token 比例 · 最终口径

**`loss_token_ratio` = 分子 ÷ 分母。分子** = assistant 消息 content（思考文字 text block + bash 命令，`tool_use` 渲染成 ` ```bash ` 块）；**分母** = system + user（TASK.md / 命令输出）+ 分子；**thinking 段既不进分子也不进分母**，单独出 `thinking_tokens` 一列。理由：thinking 不进 SFT 数据集，不在训练样本里，放进分母会人为压低比例。另出 `ratio_if_thinking_counted`（thinking 只进分母）做对照，两个数都给。
tokenizer = **tiktoken `cl100k_base`**（⚠️ 非 Qwen 分词器，量级参考；装不上退化为字符比并在 `tokenizer` 字段标 `chars`），BPE 缓存落 `.tiktoken_cache/` 免得 `/tmp` 被清后要联网重下。样例（**只验管道，数字不代表 solver**）：system 853 / user 34236 / assistant 27521 / thinking 0 → ratio **0.4396**。
